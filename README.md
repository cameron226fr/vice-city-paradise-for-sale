# VICE CITY: PARADISE FOR SALE

An interactive, neon-soaked fictional city experience inspired by
the atmosphere of 1980s Miami and retro internet culture.

## Features

- Interactive neighborhood guide and city map
- Fictional business directory and community news
- Vice City Radio featuring The Pointer Sisters
- Municipal data and economic dashboards
- Housing affordability and wealth inequality experiences
- Environmental and transportation monitoring
- Interactive city budget and public opinion polls
- Theme customization and day/night controls
- Weather atmosphere effects
- Personal favorites and lifestyle recommendations

## Run locally

Open `index.html` in a modern web browser.

## Publish with GitHub Pages

1. Create a new public GitHub repository.
2. Upload the contents of this project folder to the repository root.
3. Open the repository's Settings.
4. Select Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Select the `main` branch and `/ (root)` folder.
7. Save your settings.
8. Wait for GitHub Pages to publish the website.

Your website will be available at:

https://YOUR-USERNAME.github.io/YOUR-REPOSITORY/
